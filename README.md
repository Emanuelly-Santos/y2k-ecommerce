# Y2k E-commerce

E-commerce interface inspired by 2000s (Y2K) Fashion. I built this project to practice and improve my web development skills.

# Technologies used:

* HTML5
* CSS3
* JavaScript
* Bootstrap

# Features:

- [x] Adapted layout for mobile devices

- [x] Interactive Carousel with sliding item transitions

![carousel](carousel.gif)

- [x] Menu grid

- [ ] Functional shopping cart

- [ ] Product search functionality

# How to run the project?

### You can clone the project and run it locally by following the steps below:

1. Clone the repository:
```bash
git clone https://github.com/Emanuelly-Santos/y2k-ecommerce
```

2. Enter the project
```bash
cd y2k-ecommerce
```

3. Open "index.html" in your browser, or use the **Live Server** extension in VS Code.
